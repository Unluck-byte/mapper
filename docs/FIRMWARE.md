# Прошивка ESP32-S3

PlatformIO, Arduino-ESP32 3.x (ESP-IDF 5), библиотека ArduinoJson 7.

## Сборка и прошивка

| Команда | Что |
|---|---|
| `pio run -t upload` | основная прошивка по USB |
| `pio run -e mapper-ota -t upload` | основная прошивка по Wi-Fi (`mapper.local`) |
| `pio run -e sensortest -t upload` | тест датчиков |
| `pio run -e drivetest-ota -t upload` | тест ходовой по Wi-Fi (`drivetest` — по USB) |
| `pio run -e ustest -t upload` | простой тест ультразвуков (монитор порта) |
| `pio device monitor` | консоль (115200) |

- Wi-Fi: `include/secrets.h` (из `secrets.h.example`), сеть только **2.4 ГГц**. `PC_IP` пустой — машинка ищет комп
  широковещательно.
- Прошивка по воздуху: машинка сама подключается обратно к компу на TCP-порт **3233** (задан в `platformio.ini`),
  в файрволе он должен быть открыт: `sudo ufw allow 3233/tcp`.
- Прошивка по USB при включённой батарее — только с диодом SS34 или со снятым проводом 5V к ESP.
- Если после прошивки по USB монитор молчит — плату держат линии DTR/RTS; открыть монитор заново или нажать RST.

## Модули

### `main.cpp`
Запуск: `hwBegin` → калибровка гироскопа 1.5 с (не трогать машинку) → `tofBegin` (дальний режим) →
`robotBegin` → `netBegin` → `cliBegin`. Главный цикл без задержек: `hwUpdate`, `tofUpdate`, `robotUpdate`,
`netUpdate`, `cliUpdate`, светодиод.

Светодиод: мигает красным — нет Wi-Fi; жёлтый — Wi-Fi есть, программа на компе не отвечает; зелёный — всё на связи;
синий — скан; мигает фиолетовым — сработала защита.

С флагом `-DDEBUG_BOOT` печатает шаги запуска и «пульс» цикла.

### `hw.*` — железо
- **Моторы:** LEDC, **500 Гц**, 10 бит. На 10 кГц MX1508 с моторами TT трогался только с 70% (замерено), на 500 Гц — с 25%.
  `motorsSet(l, r)` −1…1, инверсия из `config.h`.
- **Энкодеры:** аппаратные счётчики PCNT, считаются оба фронта, фильтр помех 10 мкс. Направление берётся из команды
  мотору (энкодеры одноканальные). `encReadDeltas()`, `encTotal[]`.
- **Гироскоп MPU6050:** 250 Гц, DLPF 44 Гц, **±500 °/с** (на ±250 упирался при быстрых поворотах), интегрирование курса. Пока машинка стоит (моторы выключены),
  ноль подстраивается сам (τ≈1 с, ошибка до 8 °/с), а «вращение» в покое обнуляется — так курс не уплывает
  после включения питания моторов. Быстрее 8 °/с (крутят руками) — учитывается.
- **HC-SR04:** по очереди перед/зад каждые 35 мс, TRIG 20 мкс, ECHO меряется прерыванием **ESP-IDF**
  (`gpio_isr_handler_add`, ANYEDGE). Arduino `attachInterrupt` на этой сборке терял большую часть фронтов.
  Нет эха → 3000 мм («далеко»). Диагностика: `S.usPulses[]`, `S.usHits[]`.
- **ИК пола:** антидребезг 3 замера по 5 мс. `CLIFF_ACTIVE HIGH` — у FC-51 LOW = видит пол.
- **Батарея:** АЦП GPIO1, сглаживание. Меньше 5 В — считается «нет батареи», защита по напряжению отключена.
- **Серва:** LEDC 50 Гц 14 бит, 500–2400 мкс.

### `tof.*` — TOF400F
Modbus RTU 115200: регистр 0x10 — расстояние, 0x04 — режим (0 обычный, 1 точный, 2 дальний, 3 быстрый),
**0x05 — период измерения, мс** (с завода 500!), перезагрузка — запись 0x1000 в 0x01.
При старте прошивка ставит режим и период `TOF_PERIOD_MS` = 50 мс (если отличаются — пишет и перезагружает модуль,
значения хранятся в нём). Опрос без блокировки каждые 15 мс (тайм-аут 80 мс). 0 = нет цели.
К показаниям прибавляется `TOF_OFFSET_MM` (датчик занижал на 2 см — проверено линейкой).

**Важно:** у UART1 на ESP32-S3 выводы по умолчанию RX=15, TX=16 — это TRIG переднего и ECHO заднего
ультразвука. `Serial1.end()` до первого `begin()` их перенастраивал, поэтому `end()` вызывается только если порт
уже запускали, а после `begin()` выводы ультразвука настраиваются заново (`usReinit()`).

### `robot.*` — поведение
Режимы: `IDLE`, `MANUAL` (джойстик), `PATH` (маршрут), `TURN`, `SCAN`, `TEST`.

- **Цикл 50 Гц.** Одометрия: путь стороны — по двум энкодерам; если одно колесо буксует (в 1.6 раза больше
  соседнего) или молчит — берётся другое. Курс — от гироскопа.
- **Скорость сторон:** ПИ-регулятор с прямой связью по замеру на полу (`MOTOR_PWM_MIN` ≈ 260 мм/с … `MOTOR_PWM_MAX` ≈ 1000 мм/с).
  ШИМ не опускается ниже порога трогания (колесо либо крутится, либо выключено), интеграл не накручивается в пределах.
- **Упор (stall):** ШИМ > MIN+0.15, а колёса стоят 1.5 с → стоп, событие `blocked: stall`.
- **Маршрут:** поворот на месте к точке (ошибка < 4°), потом езда с подруливанием; отклонение > 29° — снова поворот.
- **Скан 360°:** серва 0→180° с шагом 3° (пауза 45 мс на точку) → разворот на 180° → серва 180→0°.
  Замер на угле берётся только если он сделан целиком после остановки сервы (ответ позже,
  чем остановка + 45 мс + период TOF). Каждая точка: угол машинки + угол сервы + расстояние. Если скан прервали (например, упор на развороте),
  уже снятые точки (≥20) всё равно отправляются (`scan_done` с `partial:1`).
- **Защита (всегда):** батарея < 9.6 В — моторы выключены; пропасть — вперёд нельзя; впереди ближе 18 см
  (на маршруте — 10 см, ультразвук + TOF, когда серва смотрит вперёд) — вперёд нельзя; сзади ближе 15 см — назад
  нельзя; на маршруте любая защита останавливает поездку. Джойстик молчит 0.5 с или комп — 3 с → стоп.

### `net.*` — связь
Wi-Fi STA, UDP: машинка слушает 4211, шлёт на 4210 (на адрес компа, пока не найден — широковещательно).
Телеметрия 10 раз/с, скан — кусками по 40 точек, прошивка по воздуху (ArduinoOTA, `mapper.local`).
Протокол: [PROTOCOL.md](PROTOCOL.md).

### `cli.*` — консоль (монитор порта)
```
st              все датчики одной строкой
w               статус 5 раз/с (ещё раз — выкл)
enc             счётчики энкодеров 5 раз/с
mot L R [мс]    сырой ШИМ сторон -1..1 (КОЛЁСА В ВОЗДУХЕ)
servo ГРАД      серва 0..180 (90 = вперёд)
calib           калибровка гироскопа (2 с не трогать)
fwd ММ          проехать вперёд (назад — минус)
turn ГРАД       повернуться (+ влево)
scan            скан 360°
stop            стоп
zero            обнулить положение
wifi            состояние сети
```

## Настройки `include/config.h`

| Параметр | Значение | Смысл |
|---|---|---|
| `MOTOR_L_INVERT` / `R` | true / false | направление сторон (проверено drivetest) |
| `MOTOR_PWM_FREQ` | 500 | частота ШИМ моторов, Гц |
| `MOTOR_PWM_MIN` | 0.24 | порог трогания на полу (9 В); меньше этого ШИМ колесу не даётся |
| `MOTOR_PWM_MAX` | 0.75 | предел (9 В × 0.75 ≈ 6.7 В в пике) |
| `WHEEL_DIAM_MM` | 65 | |
| `ENC_SLOTS` × `ENC_EDGES` | 20 × 2 | 5.1 мм на фронт |
| `TRACK_MM` | 235 | **эффективная** колея по замеру (геометрическая 150 — колёса проскальзывают на повороте) |
| `MAX_SPEED_MM_S` / `PATH_SPEED_MM_S` | 450 / 300 | джойстик / маршрут (порог трогания ≈ 290 мм/с) |
| `TURN_RATE_RAD_S` | 1.5 | ≈ 86 °/с |
| `ACCEL_MM_S2` | 2000 | почти без плавного разгона |
| `GYRO_SIGN` | 1 | + = против часовой |
| `SERVO_DIR` | 1 | 180° = влево |
| `TOF_MODE_SCAN` | 2 | дальний режим |
| `TOF_OFFSET_MM` | 20 | поправка дальности |
| `TOF_PERIOD_MS` | 50 | период измерения модуля (рег. 0x05) |
| `TOF_POS_X_MM` | 60 | серва впереди центра |
| `SCAN_STEP_DEG` / `SCAN_SETTLE_MS` | 3 / 45 | шаг и пауза скана |
| `US_MAX_MM` / `US_SLOT_MS` | 3000 / 35 | ультразвук |
| `CLIFF_ACTIVE` | HIGH | уровень «пропасть» |
| `SAFE_FRONT_MM` / `_PATH_MM` / `SAFE_REAR_MM` | 180 / 150 / 150 | дистанции защиты |
| `BAT_LOW_MV` | 9600 | |

Геометрия в `pc/mapper/config.py` должна совпадать (радиус машинки, положение TOF, шаг скана).

## Тестовые прошивки

### `sensortest` — датчики без компа
ESP поднимает свою сеть **`mapper-test`** / пароль **`12345678`** → http://192.168.4.1.
Показывает TOF (и автоматически ищет его: прямое/перекрёстное подключение, 8 скоростей), MPU6050 (курс, ускорение,
наклон, температура), оба ультразвука с диагностикой («нет сигнала ECHO / датчик жив, эха нет / ок»), ИК пола,
серву (качать / вручную / по расстоянию). Прошивка по воздуху тоже есть (комп должен быть в сети `mapper-test`).

### `drivetest` — ходовая
Подключается к Wi-Fi из `secrets.h`, страница — **http://mapper.local** (или IP машинки).
W/A/S/D (стрелки, Ц/Ф/Ы/В, кнопки на экране), ползунок скорости, «мёртвая рука» 0.4 с, галочки «перевернуть
левую / правую», «поменять стороны» (сохраняются во flash), счётчики энкодеров.
Для калибровки: `/raw?l=&r=&ms=` — сырой ШИМ без ограничения, `/pwm?f=` — частота ШИМ, `/enc` — счётчики.

### `ustest` — ультразвук «в лоб»
`pulseIn` по очереди для обоих датчиков, вывод в монитор порта. С `-DSTAGE=1/2/3` добавляет `hwBegin`,
`tofBegin`, опрос из `hw.cpp` — так искалась ошибка с прерываниями.
