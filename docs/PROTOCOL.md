# Протокол машинка ↔ комп

UDP, JSON, одно сообщение = один пакет.

- Машинка слушает **4211**, комп — **4210**.
- Пока машинка не знает адрес компа, она шлёт на широковещательный адрес сети. Как только от компа приходит
  любой пакет, машинка запоминает его IP. Можно задать адрес жёстко: `PC_IP` в `secrets.h`.
- Комп шлёт `hb` (пульс) раз в секунду. Нет пакетов 3 с — машинка считает связь потерянной и останавливается.

Единицы: мм, радианы (угол против часовой — плюс), мм/с. Система координат карты: x — вперёд от точки старта,
y — влево.

## Комп → машинка

| `c` | Поля | Что |
|---|---|---|
| `hb` | — | пульс |
| `drive` | `v` мм/с, `w` рад/с | ручная езда; слать чаще 0.5 с, иначе стоп |
| `stop` | — | стоп всего |
| `scan` | `id` | скан 360° |
| `turn` | `th`, `id` | повернуться на курс `th` |
| `path` | `pts: [[x,y],…]` (до 48), `id` | ехать по точкам |
| `pose` | `x`, `y`, `th` | задать положение (поправка после совмещения скана) |
| `servo` | `deg` | повернуть серву (только в покое) |
| `mot` | `l`, `r` (−1…1), `ms` | сырой ШИМ сторон — тест/калибровка |

## Машинка → комп

### Телеметрия `t: "tel"` (10 раз/с)

| Поле | Что |
|---|---|
| `x`, `y`, `th` | положение по одометрии + гироскопу |
| `vl`, `vr` | измеренная скорость сторон, мм/с |
| `v`, `w` | заданная скорость |
| `mode` | `idle` / `manual` / `path` / `turn` / `scan` / `test` |
| `blk` | сработавшая защита: `front`, `rear`, `cliff`, `bat`, `stall` или пусто |
| `wp`, `wpn`, `id` | точка маршрута, всего точек, номер задачи |
| `usf`, `usr` | ультразвук перед/зад, мм (3000 — далеко) |
| `cliff` | 1 — под датчиком пропасть |
| `tof` | TOF, мм (0 — нет цели) |
| `servo` | угол сервы |
| `bat` | батарея, мВ (0 — не измеряется) |
| `imu`, `tofok` | датчики отвечают |
| `rssi`, `up` | сигнал Wi-Fi, время работы, с |
| `enc` | счётчики энкодеров FL, FR, RL, RR (фронтов с запуска) |
| `encpin` | текущие уровни на выводах энкодеров (диагностика) |
| `gz` | скорость поворота, °/с |
| `cliffraw` | сырой уровень ИК пола (диагностика) |

### События `t: "ev"`

| `ev` | Поля | Когда |
|---|---|---|
| `scan_done` | `id`, `n`, `partial` | скан закончен (или прерван — `partial:1`), дальше идут пакеты `scan` |
| `path_done` | `id` | доехали |
| `turn_done` | `id` | повернулись |
| `stopped` | `id`, `why` | задача прервана (`cmd`, `front`, `cliff`, `stall`, `link`, `ota`…) |
| `blocked` | `why` | сработала защита |

### Скан `t: "scan"`
`{"t":"scan","id":7,"part":0,"parts":3,"x":..,"y":..,"pts":[[th_mrad, rel_deci, mm], …]}` — до 40 точек в пакете.
`th_mrad` — курс машинки в миллирадианах, `rel_deci` — угол сервы относительно «вперёд» в десятых градуса,
`mm` — дальность (0 — нет цели). `x`, `y` — положение машинки в начале скана.

## Браузер ↔ сервер (WebSocket `/ws`)

Сервер пересылает в браузер `tel`, `ev`, а также `map` (сетка карты, base64), `path`, `scanpts`, `cfg`, `log`, `link`.
Из браузера: `drive`, `stop`, `scan`, `goto {x,y}`, `auto_scan {on}`, `clear_map`, `reset_pose`, `save_map`,
`load_map`.

## Отладка TOF (только в покое)

- `{"c":"tofmode","m":0..3}` — переключить режим TOF.
- `{"c":"tofreg","r":5,"n":1[,"w":50]}` — прочитать `n` регистров модуля с `r` (и записать `w` в `r`); ответ `{"t":"tofreg","r":..,"v":[..]}` приходит отправителю. Изменения применяются после перезагрузки модуля (`r:1, w:4096`).
