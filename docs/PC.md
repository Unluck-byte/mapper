# Программа на компе

Python 3, `aiohttp` + `numpy`. Каталог `pc/`.

```bash
cd ~/mapper/pc
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt   # один раз
.venv/bin/python -m mapper.server
```
Сервер печатает адрес интерфейса `http://<ip-компа>:8080`. Порт меняется переменной `MAPPER_WEB_PORT`.

## Файрвол (Linux, ufw)

```bash
sudo ufw allow 4210/udp   # данные от машинки
sudo ufw allow 8080/tcp   # интерфейс с телефона
sudo ufw allow 3233/tcp   # прошивка по воздуху
```
Без этого машинка подключена к Wi-Fi (отвечает на ping, `mapper.local` находится), но сервер её «не видит».

## Автозапуск (systemd)

Сервер, запущенный в терминале, закрывается вместе с ним. Чтобы он работал всегда:
```bash
mkdir -p ~/.config/systemd/user
cp ~/mapper/pc/mapper.service ~/.config/systemd/user/
systemctl --user daemon-reload && systemctl --user enable --now mapper
```
Статус — `systemctl --user status mapper`, журнал — `journalctl --user -u mapper -f`,
остановить — `systemctl --user stop mapper`. Два сервера сразу не запустятся (заняты порты).

## Интерфейс (`pc/web/index.html`)

Одна страница для компа и телефона.

- Карта: чёрное — стены, светлое — свободно, серое — неизвестно. Колёсико/щипок — масштаб, перетаскивание — сдвиг.
- **Клик по карте** (режим «Клик: ехать») — маршрут и поездка.
- **Джойстик** (телефон) / **WASD** (комп), **пробел** или **СТОП** — стоп.
- **Скан** — 360° на месте. **Автоскан** — сканировать после каждой поездки.
- **За машинкой** — карта следует за машинкой.
- **Сохр. / Загр.** — карта в `pc/maps/`; после загрузки поставить машинку туда же, откуда начинали.
- **Очистить**, **x,y=0** — сброс карты / положения.
- Сверху — показатели: связь, режим, защита, датчики, Wi-Fi.

## Как строится карта

- **Сетка** (`grid.py`): клетка 25 мм, 480×480 (12×12 м), лог-шансы: попадание +0.9, луч прошёл −0.4.
  Ответ 0 («нет цели») — свободными считаются только первые 800 мм.
- **Поправка на широкий луч** (`icp.py: beam_correct`): у TOF поле зрения ~27°, наискосок стена получается
  «размазанной» и выпуклой. Каждая точка сдвигается к краю конуса по наклону соседних расстояний.
- **Совмещение скана с картой** (`icp.py: match`): перебор сдвигов ±300 мм и поворотов ±11° по «полю
  правдоподобия» (грубо → точно). Защиты от ложных поправок:
  - качество ниже 0.50 или прирост меньше 0.03 — не исправлять;
  - поправка больше 100 мм — только при качестве ≥ 0.70;
  - не больше, чем могла ошибиться одометрия (60 мм + 20% пути, 3° + 3° на метр);
  - вдоль «коридора» (где сдвиг не меняет качество — проверка по гессиану) положение не трогается.
- **Маршрут** (`planner.py`): A* по карте с «раздутыми» стенами (радиус машинки 140 + запас 50 мм), неизвестные
  клетки — дороже в 2.5 раза, цель внутри препятствия сдвигается к ближайшей свободной, путь упрощается до точек
  поворота с прямой видимостью.
- **Препятствие на маршруте**: машинка остановилась по защите → скан → новый маршрут (до 3 попыток).
- **Ручная езда** дополнительно проверяется по карте: вперёд в известную стену не пустит.

## Симулятор (`sim.py`)

Виртуальная комната (коробка, диван, перегородка), тот же протокол, что у машинки. Моделирует широкий луч TOF,
конус ультразвука, дрейф гироскопа, проскальзывание колёс, ту же защиту, что в прошивке. В телеметрии есть
`gt` — истинное положение (на карте пунктирный круг), сервер печатает настоящую ошибку `[sim]`.

## Настройки `pc/mapper/config.py`

Порты, размер клетки и карты, лог-шансы, геометрия датчика и машинки (должна совпадать с `config.h`),
параметры совмещения и маршрутов — с комментариями в файле.

## Помехи на карте
- **Ползунок «Помехи» (0–6, по умолчанию 1).** Клетка стены, у которой в радиусе 15 см меньше N других клеток
  стены, считается помехой: планировщик маршрута её не видит, на экране она не рисуется. Карта при этом не стирается,
  сдвинь ползунок назад — точки вернутся. 1 убирает одиночные точки, 2 — пары; 3 и выше могут съесть редкие стены
  после одного скана (точки дальней стены идут через ~10 см).
- **След машинки.** Где машинка проехала (круг 10 см под центром), клетки помечаются свободными, поэтому обратный
  путь всегда открыт. Карта на странице обновляется раз в 2 с.
- Настройки: `NOISE_RADIUS_MM`, `NOISE_LEVEL`, `TRAIL_FREE_MM` в `pc/mapper/config.py`.
